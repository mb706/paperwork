1. **Critical — KTX2 metadata contradicts the pixels.** [assemble.py:38](/home/mewse/browsergame/game/scripts/assets/assemble.py:38), [assemble.py:94](/home/mewse/browsergame/game/scripts/assets/assemble.py:94). Cached XUBC7 pages declare sRGB transfer (`2`) and straight alpha (`flags=0`), but contain premultiplied, display-encoded values intended for UNORM sampling. The RGBA8 fixtures declare linear transfer and premultiplied alpha instead. A loader respecting production metadata will darken colours or multiply alpha twice, despite passing fixture tests. **Fix:** explicitly encode the intended transfer and premultiplication metadata, without multiplying pixels again; validate DFDs against the upload/blending contract.

2. **Major — Inserter shadow placement requires an undocumented renderer extension.** [post.py:463](/home/mewse/browsergame/game/scripts/assets/post.py:463), [manifest.py:184](/home/mewse/browsergame/game/scripts/assets/manifest.py:184). Moving-part shadows are lowered to ground height and require `shadowShoulder` in shadow-array pixels, plus separately pivoted `_shadow` parts. §15.7 specifies neither that field nor this shadow transform. A renderer applying the visible shoulder transform to shadows misses their intended eastward displacement—about 0.67 tile here. **Fix:** bind the names, units and drawing formula in §15.7 and its fixtures before the renderer implements them.

3. **Major — The renderer fixtures violate B2’s exact composition.** [fixture.py:128](/home/mewse/browsergame/game/scripts/assets/fixture.py:128), [fixture.py:251](/home/mewse/browsergame/game/scripts/assets/fixture.py:251), [fixture.py:299](/home/mewse/browsergame/game/scripts/assets/fixture.py:299). Layer cells receive transparent gutters instead of the complete frame’s neighbouring pixels. Read-only comparisons against a whole-frame reference preserving the atlas mip grid measured furnace errors of **ΔE 13.8 at level 0 and 27.8 at mip 1**, against ≤0.5. The radar also draws 64 source pixels twice because its base includes the layer rectangle. Existing fixture checks return no errors. **Fix:** generate proper base pieces, real layer gutters and a translucent boundary case; check decoded composition.

4. **Major — Animated shadow output is silently discarded.** [render.py:220](/home/mewse/browsergame/game/assets/blender/render.py:220), [post.py:298](/home/mewse/browsergame/game/scripts/assets/post.py:298), [post.py:359](/home/mewse/browsergame/game/scripts/assets/post.py:359). A full-frame entity with `anim_shadow=True` renders shadow PNGs per frame, but post-processing never consumes them and emits no shadow part. Layered animated shadows instead raise `NotImplementedError`. Light is also rendered only at F₀, so a moving emitter’s glow stays behind. **Fix:** carry animated channels through frame-axis tables and require them in semantic validation.

5. **Major — Multiple-layer handling is not ready for general entities.** [post.py:370](/home/mewse/browsergame/game/scripts/assets/post.py:370), [quality.py:163](/home/mewse/browsergame/game/scripts/assets/quality.py:163). Layer counts are taken from the first combination although merging happens separately per direction/variant. If another direction leaves two layers disjoint where the first merged them, post-processing can index beyond that first layer list. The composite check also draws only one layer against a base cut around *all* layers, falsely rejecting valid disjoint layers. **Fix:** define consistent layer slots across combinations and compare complete compositions for every populated combination. The cached keypunch passes because its two source layers merge into one.

6. **Major — Cache keys omit real dependencies.** [plan.py:112](/home/mewse/browsergame/game/scripts/assets/plan.py:112), [assemble.py:83](/home/mewse/browsergame/game/scripts/assets/assemble.py:83). `item/iron-chest` imports `entities/iron_chest.py`, but its planned inputs contain only its item script and `_models.py`. Editing the chest updates the world sprite while retaining its old icon. Encoding keys likewise omit the encoder version and DDS/encoding implementation, allowing metadata fixes to reuse stale KTX2 files. **Fix:** hash declared/transitive model dependencies and a pinned encoder/encoding implementation signature.

7. **Major — Failed builds can destroy the last usable publication.** [assemble.py:204](/home/mewse/browsergame/game/scripts/assets/assemble.py:204), [build-assets.ts:634](/home/mewse/browsergame/game/scripts/build-assets.ts:634). Assembly deletes old hashed pages before fonts, UI, manifest generation and validation finish; the new manifest is published before its gates run. A subsequent font failure leaves the previous manifest referencing deleted textures, while a quality failure leaves rejected output published. **Fix:** stage a complete generation, validate it, publish the manifest last, and garbage-collect old files only afterward.

8. **Major — Blender exceptions are not reliable process failures.** [build-assets.ts:268](/home/mewse/browsergame/game/scripts/build-assets.ts:268), [build-assets.ts:312](/home/mewse/browsergame/game/scripts/build-assets.ts:312). Blender is launched without `--python-exit-code`; command-line Python exceptions can exit successfully. If an interrupted run left a missing render record but an existing post cache, a failed rerender can be followed by skipping post-processing and successfully publishing cached output. **Fix:** set a nonzero Python exception exit code and verify every requested job’s complete outputs before accepting the batch.

9. **Major — Binding quality failures have been converted into success.** [checks.py:139](/home/mewse/browsergame/game/scripts/assets/checks.py:139), [checks.py:312](/home/mewse/browsergame/game/scripts/assets/checks.py:312), [checks.py:371](/home/mewse/browsergame/game/scripts/assets/checks.py:371). 10. **Minor — `--no-render` cannot reuse normal render keys.** [build-assets.ts:596](/home/mewse/browsergame/game/scripts/build-assets.ts:596). Existing renders were keyed with the actual version, so the documented option looks in different directories and fails. **Fix:** retain the actual version when calculating keys, independently of whether rendering is enabled.
