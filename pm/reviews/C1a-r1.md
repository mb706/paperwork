Read-only review; failures were reproduced with in-memory inputs. Full CI was not run because it writes artifacts. Paths below are relative to `game/`.

1. **Major — Unit conversion can emit infinity.** [emit/tables.ts:205](/home/mewse/browsergame/game/scripts/data-stage/emit/tables.ts:205). A valid, finite `heat_capacity_kj_per_k: 1.0e+308` becomes `Infinity` after conversion to J/K. The M1 stage succeeds and writes it into `prototypes.bin`; JSON omits this field, so its finite-number check provides no protection. Validate converted values and reject non-finite floats at the binary writer boundary, with source diagnostics.

2. **Major — Missing research counts become zero-cost research.** [schema/technologies.ts:71](/home/mewse/browsergame/game/scripts/data-stage/schema/technologies.ts:71), [emit/tables.ts:436](/home/mewse/browsergame/game/scripts/data-stage/emit/tables.ts:436). Removing `cost.count` from `electric-mining-drill` passes the TypeScript stage and emits zero. Python rejects it, but `npm run data`, development and production data generation do not run that validator. Require exactly one of `cost.count` and `count_formula` for paid technologies.

3. **Major — Capability closure overstates obtainability.** [capabilities.ts:166](/home/mewse/browsergame/game/scripts/data-stage/capabilities.ts:166). Every listed resource contributes its yield immediately, and every included recipe participates regardless of unlock status. Adding water to M0 passes without an offshore pump. Adding the pipe entity and recipe passes despite no included technology enabling it; the emitted recipe is disabled at start. Compute reachability using extraction requirements, enabled recipes and reachable unlocks, and validate trigger targets inside the capability set.

4. **Major — Entity triggers can resolve to item IDs.** [emit/tables.ts:369](/home/mewse/browsergame/game/scripts/data-stage/emit/tables.ts:369). For an entity target, resolution searches items before entities. A `build-entity` trigger naming `iron-chest` therefore emits an item target because both prototypes share that name. Resolve the namespace from the trigger’s discriminant and target field; reject unresolved or ambiguous targets instead of emitting “none.”

5. **Major — Advertised milestone binaries silently discard gameplay data.** [emit/protos-bin.ts:57](/home/mewse/browsergame/game/scripts/data-stage/emit/protos-bin.ts:57). `META` contains only start inventory. Other required blocks, technology effects and the model-collapse expression have no complete emission path. Changing `meta.world.w0` to `123` produced identical M1 binary and JSON hashes. This omission is not identified as a deviation in the report. Emit the required records, or explicitly reject affected builds until supported.

6. **Major — An empty level range bypasses expression validation and cross-checking.** [formulas.ts:239](/home/mewse/browsergame/game/scripts/data-stage/formulas.ts:239). An infinite technology with `first_level: 65536` skips the loop and receives `max_level: 65535`. Even `1/(L-65536)` is accepted without evaluating its first level. Both fixture generators then process zero points. Reject unsupported starting levels and assert that every formula’s checked range is nonempty and its cap reaches its first level.

7. **Minor — Half-up rounding changes already integral costs.** [expr.ts:403](/home/mewse/browsergame/game/scripts/data-stage/expr.ts:403). `unitCount(4503599627370497)` returns `4503599627370498`: adding `0.5` rounds before `floor` executes. This lies within the declared range. Python uses the same faulty expression, while the Rust cross-check hashes unrounded results. Round using the fractional part, and add independent goldens around `2^52` and `2^53`.

8. **Major — Determinism bans have ordinary syntax bypasses.** [check-arch.ts:360](/home/mewse/browsergame/game/scripts/check-arch.ts:360). Confirmed accepted examples include `globalThis.Math.random()`, `Math["random"]()` and `const {random: rng} = Math; rng()`. Randomness through destructured dynamic imports and named re-exports also escapes checking. Resolve bindings and static properties, or conservatively reject unsupported access forms in deterministic modules. Add regression fixtures for each form.

9. **Major — Dynamic imports bypass layer boundaries.** [check-arch.ts:308](/home/mewse/browsergame/game/scripts/check-arch.ts:308). Only string-literal sources are checked. In UI code, ``import(`../render/a.ts`)`` passes despite having a completely static target; variable imports pass too. Evaluate constant template literals and reject non-static imports unless they use an explicitly checked allow-list.

10. **Minor — The Rust I/O guard misses grouped imports.** [check-arch.ts:502](/home/mewse/browsergame/game/scripts/check-arch.ts:502). `use std::{fs, env, net}; fs::read("x");` produces no violation. These APIs are absent from the Clippy bans, so this idiomatic spelling bypasses enforcement entirely. Use Rust syntax/import analysis or resolved API bans, with grouped and renamed imports in the negative fixtures.

11. **Minor — Generated-file hashes do not establish generator ownership.** [schema-gen.ts:119](/home/mewse/browsergame/game/scripts/schema-gen.ts:119), [lib/generated.ts:69](/home/mewse/browsergame/game/scripts/lib/generated.ts:69). An extra handwritten file carrying a valid data-stage header and recomputed body hash passes the header check. Schema freshness ignores it, and data freshness checks only its known output paths. Check the complete output inventory, expected generator, source and schema identity; reject extra generated files.

12. **Major — Release builds omit `gen.wasm`.** [cargo-plugin.ts:199](/home/mewse/browsergame/game/scripts/cargo-plugin.ts:199). Assets are emitted only when their virtual module is imported. The scaffold imports only `virtual:sim-wasm`; the existing release directory and manifest consequently contain only `sim`. The build neither ships nor hashes the second required module. Emit both modules unconditionally, require both manifest entries, and test an actual production bundle.

13. **Minor — The release cache can skip an invalid artifact set.** [ci.ts:111](/home/mewse/browsergame/game/scripts/ci.ts:111). Cache validity requires only `sim.wasm` to exist. Missing `gen.wasm` or modified output bytes still permit a skip. `.cargo/config.toml`, relevant compiler environment and optimizer identity are also absent from the key. Verify both output hashes and complete build inputs; the inexpensive feature gate can run on every CI invocation.

14. **Minor — Watch inputs exclude compiler and schema dependencies.** [data-stage-plugin.ts:17](/home/mewse/browsergame/game/scripts/data-stage-plugin.ts:17). Editing `expr.ts` leaves served data unchanged until another watched input changes or Vite restarts. With C1b, schema generation can rebuild Rust while prototypes retain the previous schema hash. Watch the stage’s implementation dependencies and generated schema identity, and sequence dependent regeneration before serving refreshed data.

15. **Major — Failed rebuilds continue serving previous results.** [cargo-plugin.ts:122](/home/mewse/browsergame/game/scripts/cargo-plugin.ts:122), [watch-run-plugin.ts:48](/home/mewse/browsergame/game/scripts/watch-run-plugin.ts:48). Failures are swallowed after broadcasting an overlay; previous modules and data remain available. A fresh browser connection can therefore load apparently working results from before the failed edit without receiving that broadcast. Persist failure state and return an error for affected resources until a successful rebuild clears it.
