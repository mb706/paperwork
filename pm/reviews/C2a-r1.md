1. **Major — Remapping can produce different state on native and wasm32.** [remap.rs:347](/home/mewse/browsergame/game/crates/sim/src/remap.rs:347) computes a block offset using unchecked `usize` arithmetic. Class 10 has 320 slots: block 13,421,773 gives offset 4,294,967,360 natively, but 64 on wasm32 release. A removed entity can carry this corrupt `InvRef`: native skips clearing it; wasm can clear slots 64–383 of real inventories. Removing the entity before ownership validation hides the invalid reference. **Fix:** validate original references before remapping; use checked multiplication, addition, and bounds checks, returning `ERR_LOAD_FORMAT`.

2. **Major — Malformed coordinates can trap during loading or be accepted after overflow.** [world.rs:206](/home/mewse/browsergame/game/crates/sim/src/world.rs:206), [save.rs:401](/home/mewse/browsergame/game/crates/sim/src/save.rs:401). Loading rebuilds spatial indexes before checking invariants, and footprint arithmetic uses unchecked `i32` addition/subtraction. Changing a golden chest’s `x2` to `i32::MAX` makes checked builds overflow at `x2 + w`; the existing release executable accepts the save because wrapped coordinates alias existing chunk keys. **Fix:** validate coordinates and world extents before rebuilding; calculate footprints with checked arithmetic or wider integers.

3. **Major — Enabling NO_SLEEP invalidates every existing watch-list ID.** [sched.rs:226](/home/mewse/browsergame/game/crates/sim/src/sched.rs:226). `set_no_sleep(true)` calls `reset`, which replaces `lists` with only the wheel buckets, while systems retain their `ListId`s. The sequence `alloc_list(); set_no_sleep(true); notify(old_id)` indexes past the vector. Disabling NO_SLEEP also leaves systems holding invalid IDs. The tests enable the flag before allocating lists, so they miss this. **Fix:** preserve allocated watch-list identities while clearing registrations; test toggling the flag on an established factory.

4. **Major — Load accepts inventories too small for their owners.** [save.rs:430](/home/mewse/browsergame/game/crates/sim/src/save.rs:430). Despite the function’s documentation, validation checks only whether a character has an inventory. Swapping a golden chest’s and player’s inventory references passes release loading and hashing: ownership remains unique, but the player receives a 32-slot block for an 80-slot inventory. Later inventory operations can panic or silently omit slots. **Fix:** check each owner’s required capacity and canonical size class, and validate bars, filters, and hand origins against the logical inventory size.

5. **Major — ABI blob retention has no memory bound.** [context.rs:255](/home/mewse/browsergame/game/crates/sim/src/context.rs:255). `BlobPut` accepts all remaining bytes, and every distinct hash causes another full copy into `self.blobs`. Repeated calls without a tick grow memory indefinitely; duplicate detection also becomes quadratic. A hostile caller can exhaust WASM memory before closure preflight runs. **Fix:** enforce per-blob, aggregate-byte, and entry-count limits before copying, with structured refusals and a bounded lookup structure.

6. **Minor — Handle-to-serial conversion bypasses generation validation.** [world.rs:177](/home/mewse/browsergame/game/crates/sim/src/world.rs:177). Destroy A, reuse its row for B, then call `serial_of(old_handle_a)`: it returns B’s serial. Any saved reference subsequently using this helper can become a valid reference to the replacement after loading. The ownership invariant check also compares the reverse handle by slot alone. **Fix:** require `is_live(h)` during conversion and compare complete handles in invariants; add a stale-handle conversion test across reuse.

7. **Minor — A checked piecewise table can still manufacture NaN.** [piecewise.rs:91](/home/mewse/browsergame/game/crates/det/src/piecewise.rs:91). The finite, ascending table `[(0, 0), (1, f64::MAX), (2, -f64::MAX)]` passes construction, but evaluating exactly at 1 computes `MAX + (-∞ × 0)`, producing NaN. This contradicts both the documented exact-breakpoint behavior and the intended D6 protection. **Fix:** return the stored value at every exact breakpoint; reject or safely evaluate segments whose interpolation intermediates overflow. Test extreme finite values and signed zero.

8. **Minor — Wrapped long deadlines can block unrelated timers.** [sched.rs:484](/home/mewse/browsergame/game/crates/sim/src/sched.rs:484), [sched.rs:507](/home/mewse/browsergame/game/crates/sim/src/sched.rs:507). Deadlines wrap, but the heap uses ordinary numeric ordering and fires only when its minimum equals the current tick. At tick 10, delay `u32::MAX` creates deadline 9; that entry blocks a legitimate deadline 5,010 indefinitely. This matters even though `World::tick` refuses counter exhaustion. **Fix:** reject deadline overflow consistently with that policy, or implement an explicit modular-time ordering with bounded delays.

9. **Minor — Scheduler reclamation both relaxes the binding bound and allocates during steady operation.** [sched.rs:458](/home/mewse/browsergame/game/crates/sim/src/sched.rs:458), [sched.rs:467](/home/mewse/browsergame/game/crates/sim/src/sched.rs:467). Decision 2’s allowance permits 64 stale long-timer nodes with zero live registrations, contrary to §4.6’s strict twice-live bound. Sweeping takes the heap’s backing allocation into a vector, then pushes survivors into a fresh heap, causing recurring allocations under timer churn. The allocation test exercises idle ticks only. **Fix:** enforce the specified bound or explicitly amend it, preserve heap capacity during reclamation, and measure allocations under repeated sleep/wake cycles.

10. **Minor — Digest slicing retains full-collection scans.** [digest.rs:275](/home/mewse/browsergame/game/crates/sim/src/digest.rs:275), [digest.rs:301](/home/mewse/browsergame/game/crates/sim/src/digest.rs:301), [digest.rs:312](/home/mewse/browsergame/game/crates/sim/src/digest.rs:312). Every tick traverses all work timers, statistics records, and pending requests to select one shard. Once later systems populate these collections, digest cost scales with the whole collection rather than approximately 1/3,600 of it. The report acknowledges the timer case. **Fix:** maintain shard indexes with canonical record positions and benchmark populated collections.
