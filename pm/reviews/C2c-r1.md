1. **Major — Subscription limits do not bound retained requests.** [extract.rs:322](/home/mewse/browsergame/game/crates/sim/src/extract.rs:322), [extract.rs:596](/home/mewse/browsergame/game/crates/sim/src/extract.rs:596). Refused subscriptions are excluded from the limit count but still inserted, with cloned parameters. Repeated calls before extraction grow the table without bound and make limit checking quadratic. WASM accepted 2,000 requests and emitted 2,001 UI records, including hover. The version table also retains every retired ID indefinitely. **Fix:** bound outstanding refusals and total request storage, reject excess batches before cloning, and reclaim version history when subscriptions end.

2. **Major — Query units do not bound work.** [query.rs:75](/home/mewse/browsergame/game/crates/sim/src/query.rs:75), [query.rs:127](/home/mewse/browsergame/game/crates/sim/src/query.rs:127). One unit executes an entire full-state hash, serializing every saved section. On the 30,000-chunk save, `sim_query_step(1)` blocked WASM for **14–36 ms**. The shell cannot enforce §15.5’s 2 ms slice around an indivisible call; M1 growth makes this worse. **Fix:** retain hashing/serialization continuations and charge units per bounded record or byte block. The golden traces’ endpoint agreement does not establish bounded execution.

3. **Major — Implicit STATS selections bypass the key limit and trap.** [project.rs:354](/home/mewse/browsergame/game/crates/sim/src/project.rs:354), [project.rs:432](/home/mewse/browsergame/game/crates/sim/src/project.rs:432). The explicit tail checks the 256-key limit, but an empty tail collects every matching statistic. A save containing 257 item-stat rows was accepted by `sim_load`; subscribing to STATS then caused `RuntimeError: unreachable` with `Stats.entries: too_long`. **Fix:** enforce the selection limit on both paths and return status 2/reason 3, with explicit subsets or pagination. Reject invalid saved statistic keys during load, and avoid panicking on request-dependent encoding failures.

4. **Major — Failed packet delivery consumes unsent presentation state.** [extract.rs:506](/home/mewse/browsergame/game/crates/sim/src/extract.rs:506), [simabi/lib.rs:125](/home/mewse/browsergame/game/crates/simabi/src/lib.rs:125). Extraction updates held versions and subscription hashes and drains events before the ABI reserves the final envelope arena. If that reservation fails near WASM’s memory limit, `sim_extract` returns zero, but a retry omits the consumed deltas and events. This violates §15.4’s sent-state rule. **Fix:** reserve delivery storage before committing presentation changes, or stage those changes and commit only after envelope construction succeeds.

5. **Major — The pristine view cache can permanently starve unsent chunks.** [extract.rs:404](/home/mewse/browsergame/game/crates/sim/src/extract.rs:404). Every pristine held chunk needs cached content before its already-sent versions are considered. Once the 512-entry cache fills, extraction regenerates evicted, already-sent nearby chunks ahead of unsent distant ones. In WASM, a stationary view covering **1,156 generated chunks stalled at 533 delivered chunks**, unchanged through packet 150. **Fix:** skip content lookup for unchanged, already-sent pristine chunks and prioritize unsent chunks. Add a convergence test exceeding cache capacity.

6. **Major — Packet identity omits surfaces.** [extract.rs:260](/home/mewse/browsergame/game/crates/sim/src/extract.rs:260), [extract.rs:526](/home/mewse/browsergame/game/crates/sim/src/extract.rs:526). Held versions are keyed only by `ChunkKey`; changing surfaces retains matching coordinates and suppresses their initial deltas. MOVERS also checks coordinates without checking the character’s surface. A valid two-surface load reproduced both: switching to surface 1 emitted no tiles and still emitted surface 0’s character. **Fix:** include surface in retained identity or clear sent-state on surface changes, and filter movers by surface. Test overlapping coordinates on different surfaces.

7. **Major — `simtool replay` cannot consume normal browser bug bundles.** [main.rs:145](/home/mewse/browsergame/game/crates/simtool/src/main.rs:145), [save.rs:509](/home/mewse/browsergame/game/crates/sim/src/save.rs:509). The reader explicitly rejects compressed sections. The IO worker deflates save sections and puts those containers into bug bundles, so real reports fail before replay reaches the trapping closure. Raw golden saves conceal this integration gap. **Fix:** decode codec-1 sections with bounded decompression and validate their declared raw lengths. Test replay against an actual IO-produced bundle.

8. **Major — The benchmark exit criterion is incomplete.** [bench.rs:187](/home/mewse/browsergame/game/crates/simtool/src/bench.rs:187), [thresholds:53](/home/mewse/browsergame/game/crates/sim/src/testkit/bench.rs:53), [ci.ts:100](/home/mewse/browsergame/game/scripts/ci.ts:100). Native quick benchmarks pass, but CI never invokes them, Node/browser WASM benchmark runners are absent, and quick mode reuses mean-based gates instead of implementing §10.6’s p99 budget gate. CI can therefore remain green through boundary latency regressions. The copied numeric thresholds—including the unscaled eight-chunk count—are otherwise correct. **Fix:** wire the quick gate into CI, define its p99 budgets, and run the same scenarios through the WASM boundary.

9. **Minor — Declared source revisions and shared evaluation are unimplemented.** [extract.rs:715](/home/mewse/browsergame/game/crates/sim/src/extract.rs:715). Every due subscription rebuilds and hashes its body independently. Unchanged INVENTORY/HOVER records ignore their declared source revisions, and duplicate windows repeat evaluation. M0’s small records meet the benchmark, but M1’s larger inventories and panels multiply unnecessary work. **Fix:** retain source revisions and cache shared evaluation by kind, target and parameters, while keeping each subscription’s delivery and series state independent.

10. **Minor — Huge query parameters are copied before being discarded.** [simabi/lib.rs:80](/home/mewse/browsergame/game/crates/simabi/src/lib.rs:80), [simabi/lib.rs:371](/home/mewse/browsergame/game/crates/simabi/src/lib.rs:371). `Queries::start` caps retained parameters, but the ABI first clones the entire request through `Module::request`. A large malformed query temporarily duplicates its input and can exhaust memory before the intended bounded rejection. The native long-parameter test bypasses this copy. **Fix:** borrow the input buffer as `sim_tick` and `sim_extract` do, and validate parameter lengths before allocating.

11. **Minor — Clock sampling cannot establish the stated benchmark conditions.** [bench.rs:451](/home/mewse/browsergame/game/crates/simtool/src/bench.rs:451), [main.rs:339](/home/mewse/browsergame/game/crates/simtool/src/main.rs:339). The runner records machine-wide mean MHz before and after a scenario, not the pinned cores’ frequencies during timed windows. A turbo interval can escape those samples, yet its measurements enter absolute results without being flagged. **Fix:** log frequencies during each timed window, flag turbo-contaminated windows, and provide the required paired A/B workflow for hot-path comparisons.
