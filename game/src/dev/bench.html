Paperwork benchmark

This page measures the game on this machine: the simulation's M0 scenarios in a worker (WebAssembly, as in the game), whether this browser computes the simulation bit for bit as the native build does, the renderer's frame cost on the frame-budget scenes, the audio engine's offline render load, and the GPU's texture formats. It takes about two minutes; keep the tab in front, and leave the machine idle meanwhile. The results go to the dev server (bench/user-results/), where they calibrate the host's numbers.
